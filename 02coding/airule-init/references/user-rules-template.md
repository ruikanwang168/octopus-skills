# harness/USER_RULES.md 生成规则

## 文件职责

`harness/USER_RULES.md` 是用户手写规则文件，用来保存项目维护者自己的长期偏好、特殊约束和不希望被技能自动覆盖的项目规则。

这个文件属于用户，不属于 `airule-init` 的增量更新范围。

## 默认模板

仅当目标项目的新旧位置均缺少用户规则文件时，初始化模式或更新模式创建下面的占位内容；旧文件的识别与原样迁移按 `incremental-mode.md` 执行：

```md
---
last_updated: YYYY-MM-DD
status: active
owner: unassigned
---

# 用户自定义规则

本文件由项目维护者手动编写，用于记录本项目中特殊的协作偏好、业务约束和长期规则。

`airule-init` 初始化时只创建本文件；后续增量更新不会自动修改或覆盖这里的内容。

## 一、项目特殊约束

待补充。

## 二、个人协作偏好

待补充。

## 三、禁止事项

待补充。
```

## 生成规则

- 只在文件不存在且没有可迁移的旧版文件时创建；原样迁移不允许改写用户内容。
- 新建时按 `agents-template.md` 的元信息约定填写实际日期和负责人；已有文件不因缺少元信息或日期较早而被自动补头部、刷新日期或改变状态。
- 如果文件已存在，无论内容是否为空，更新模式都不自动修改。
- 可以读取该文件来理解用户偏好，但不能把它当作待同步文件改写。
- 只有用户明确说“修改 harness/USER_RULES.md”或“把这条写入 harness/USER_RULES.md”时，才允许更新。
